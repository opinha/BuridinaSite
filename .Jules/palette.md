## 2025-05-15 - [Skip-to-content & Mobile Menu ARIA]
**Learning:** Indigenous community sites with fixed headers and localized content benefit significantly from standard a11y patterns like 'skip-to-content' links and explicit mobile menu state (aria-expanded/controls) to ensure screen reader users can navigate efficiently between Portuguese and Inyrybe content.
**Action:** Always include a 'skip-to-content' link in the root layout targeting the main content area and ensure mobile toggles have localized aria-labels and state indicators.
