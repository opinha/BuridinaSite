## 2025-05-15 - [Accessibility: Grounded Localization]
**Learning:** Localizing accessibility strings (ARIA labels, skip links) into indigenous languages like Inyrybe requires grounding terms in the community's context (e.g., using 'Katirese' for skip/explore) to ensure the interface is truly inclusive and respectful.
**Action:** Always include localized ARIA attributes and accessibility helpers when implementing multi-language support for indigenous communities.
