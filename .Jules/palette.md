## 2025-05-15 - Improving Header Accessibility
**Learning:** Adding ARIA attributes (`aria-label`, `aria-expanded`, `aria-controls`, `aria-current`) to navigation components significantly improves the experience for assistive technology users without changing the visual design. It's a high-impact, low-risk micro-UX win.
**Action:** Always check interactive elements like menus and language switchers for missing ARIA attributes and state indicators.
