## 2026-07-06 - Improve Accessibility and Keyboard Navigation
**Learning:** Adding a "Skip to Content" link and proper ARIA attributes significantly improves the experience for screen reader and keyboard users. Using localized strings for these attributes is essential in multi-language applications to maintain consistency.
**Action:** Always include a Skip to Content link in the root layout and ensure interactive elements like mobile menus and language switchers have descriptive ARIA labels and states.
